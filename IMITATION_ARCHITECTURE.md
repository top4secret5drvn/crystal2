# Имитационная калибровка: архитектура и границы

Исходный аудит: [IMITATION_AUDIT.md](IMITATION_AUDIT.md), HEAD ca10cc3.
Модуль `imitation_learning.py` работает без LLM, сети и сторонних зависимостей.

## Реальный путь воздействия

Основной factual generator, волны, HDC, геном, граф и SemanticSpace сохранены.
Экспериментальный selector читает прямые подтвержденные типовые ребра, их веса,
контекст и CrystalReason. Он использует приоритет запрошенного типа, приоритеты
IS_A/PART_OF/CAUSE и переключатель речевой формы IS_A. Все эти параметры реально
меняют результат. Score_hypothesis и CalibrationProfile не оптимизируются:
они не влияют на прямой factual ответ, а conceptual plan изменяет runtime.
Новая система не обучает многошаговый поиск; «исправление рассуждения» здесь —
исправление выбора одношагового пути к уже известному отношению.

`answer(lattice, example, parameters)` не вызывает инъекцию текста, волны,
кэши, маркеры или sleep. Он возвращает Attempt: текст, отношение, путь ID,
альтернативы, confidence, параметры и provenance исходного свидетельства.
Детерминированный локальный RNG используется только для порядка мутаций.
Ни глобальный random, ни состояние ядра при оценке не изменяются.
Подтвержденность проверяется по существующему provenance; учительский текст
не создает ребер и не подтверждает гипотез.

По умолчанию обучение выключено (`Config.enabled=False`), основной
`generate_text` остается factual. `generate_text(..., mode='imitation')` требует
явно установленного `lattice.imitation_state`. Наличие сохраненных параметров
само по себе не переключает основной режим. Существующие API и типы сохранены.

## Образцы и диагностируемые ошибки

TrainingExample содержит ID, query, несколько references, допустимые формальные
relations, context, world, concept_ids, источник и доверие коррекции, error_label,
train/validation/test. Отношение — `(subject_label, EDGE_NAMES type, target_label)`.
Концептуальные ID и human label сохраняются как метаданные, не превращаются в факты.
Если world задан, требуется явная однозначная привязка концов ребра к этому миру.
Примеры исходной фикстуры — демонстрации ответа в контексте, не универсальные истины.

Запрос ограниченной грамматики: `IS_A яблоко`, `PART_OF модуль`, `CAUSE нагрев`;
можно задать только метку субъекта, но тогда намерение может быть неоднозначным.

- A: выбранное отношение корректно, форма не входит в допустимые формулировки.
- B: нужные концы отношения сохранены, выбран неверный тип.
- C: корректный ответ уже в памяти, выбран иной путь/целевой концепт.
- D: допустимого подтвержденного отношения нет; мутации не выполняются.
- E: равноприоритетные альтернативы либо нет семантической разметки.

Причины B и C могут пересекаться: диагностика сохраняет альтернативы. Нет
универсального автоматического установления причин ошибки по одной русской фразе.
Без relations семантическая оценка None, обучение не принимается. Human label
записывается отдельно, не отменяя проверку наличия знаний.

## Оценка и локальная адаптация

Семантика оценивается по структурной трассе, не сходству строк. Отдельно считаются
точное отношение, тип, сохраненные существенные концы, форма и соответствие
уверенности эталону. Форма — нормализация регистра/пунктуации и список разрешенных
формулировок. Это ограниченный тест, не семантический оценщик русского языка.
Буквально правильная строка с неверным структурным отношением не получает semantic=1.

Score: 0.6 semantic + 0.15 type + 0.1 concepts + 0.1 form + 0.05 confidence quality.
Если формальный эталон неизвестен, score=None, а не искусственный ноль/единица.
При отсутствии формы ее компонент не оценивается как успех.

`ImitationLearner.train_on_example(example, config)`:

1. Получает исходную трассу и диагноз. Требует train и trusted correction.
2. Проверяет отдельный размеченный trusted validation; ID и полные запросы
   текущего train не должны пересекаться с validation. Test нельзя передавать
   как обучающий или контрольный split.
3. До оценки кандидатов формирует фиксированные изменения только из train-диагноза.
   Один кандидат меняет ровно один параметр на ±0.25 либо выбирает форму IS_A.
   Веса ограничены [-2,2], переключатель формы — 0/1.
4. Оценивает кандидатов на текущем train и контролях. Validation/test ответы
   не создают мутации. Validation используется только для допуска изменения;
   test не передается learner вообще.
5. Принимает строгий train gain только без падения score и любой известной компоненты качества каждого контроля.
   В guarded режиме контролями также становятся ранее принятые train-навыки.
6. Применяет только лучший набор параметров, сохраняет предыдущую версию,
   происхождение и scope, before/after, оценки и причины отклонения.
   Неудачные временные параметры просто отбрасываются, поскольку не применялись.

Один вызов — один раунд принятия, не бесконечный цикл. Не более 12 кандидатов
по умолчанию (реально максимум восемь одношаговых весовых или одна форма),
300 suite-evaluations; жесткий предел Config — 64/4096. Каждый ответ обходит
не более 4096 ребер. При превышении возвращается неопределенность.
Начальный trace и финальная трасса — не более двух дополнительных ответов сверх
suite-evaluations; верхняя граница просмотров ребер `(max_evaluations+2)*4096`.
Если нет допустимого улучшения, вызов завершается с reason.
Повторный вызов может исправить другой компонент ошибки (например, форму после выбора).

Это поиск по небольшому **заранее заданному** семейству правил. Правило регулярного
творительного падежа написано разработчиком; обучение выбирает его, а не открывает
русскую морфологию. Поддержаны ограниченные окончания -а и твердый согласный.
Исключения, мягкие основы, склонение всех типов PART_OF/CAUSE и свободный порядок
слов не решены. Неизвестные формы не исправляются догадками из теста.

## Сохранность, история и откат

Параметры immutable; временные кандидаты не заменяют их до принятия. Экспорт
и восстановление истории копируют данные, не разделяя изменяемые контейнеры.
`rollback()` возвращает предыдущую версию параметров и записывает действие.
История коррекций и встреченных навыков сохраняется; откат не удаляет свидетельства.

Optional `imitation_state` в существующем CRC JSON trailer сохраняет schema=1,
параметры, историю, предыдущие версии и контрольные навыки. Binary layout/MAGIC
не меняются, старые файлы получают None. Сохранение истории не является подтверждением
знаний. Консолидация во сне отключена; sleep не вызывает этот learner.
Ручной CLI save пишет новый snapshot и отказывается перезаписывать существующий.

## Интерактивный пример

```sh
python3 examples/imitation_session.py /tmp/new-imitation-demo
python3 imitation_learning.py --snapshot /tmp/new-imitation-demo/demo.cry \
  --examples /tmp/new-imitation-demo/examples.json
```

```text
калибровка старт
калибровка пример яблоко
калибровка обучи
калибровка обучи
калибровка отчёт
калибровка сохрани /tmp/new-imitation-demo/trained.cry
калибровка откат
выход
```

`пример` принимает train ID из JSON, чтобы сохранить явные splits и semantic gold.
`эталон <текст>` меняет только references выбранного примера; текст не создает знания.
Отчет содержит исходный/итоговый ответ, эталон, диагноз, изменения, результаты
контролей, provenance и причину принятия. Без validation и знаний обучение не идет.
Отдельная CLI-сессия выбрана вместо изменения основного REPL и его автозагрузки.

## Что различается

Запоминание пары текстов — отдельный baseline. Исправление формальной связи —
правильный выбор уже подтвержденного ребра. Исправление стратегии — изменение
общего приоритета, применимого к другим субъектам. Получение новых знаний этим
модулем не выполняется. Изменение собственного алгоритма обучения не реализовано:
это не полноценное метаобучение и не самостоятельная эволюция архитектуры.
