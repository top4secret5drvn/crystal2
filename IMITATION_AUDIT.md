# Аудит перед имитационной калибровкой

Исходный origin/main: ca10cc3 (PR #4), отдельная ветка experiment/imitation-calibration.

- Factual `LanguageMembrane.generate_text` выбирает максимальный вес прямого
  подтвержденного ребра и фиксированную конструкцию. Запрос не ранжирует типы;
  IS_A выводит исходную словоформу («является фрукт»).
- `build_conceptual_plan` вызывает backward wave, инжектирует маркеры, меняет
  blackboard и runtime. Его нельзя без изоляции вызывать внутри оптимизатора.
- `score_hypothesis` использует coverage/connectivity/causality с фиксированными
  коэффициентами; factual generator его вообще не вызывает.
- `tick_backward` зависит от CalibrationProfile, HDC, графа и текущего состояния.
  Эти параметры не изменяют выбор прямого factual ответа.
- Геном управляет decay/entropy/depth и мутирует во сне, но не выбором конструкции
  factual generator. Оптимизировать весь геном по текстовому совпадению некорректно.
- SemanticSpace влияет только на диагностику/гипотезы, off по умолчанию.
- Снимки имеют совместимый CRC JSON trailer: новый режим можно сохранить там
  необязательным полем, без изменения binary layout и прежних методов API.

Выбран узкий реальный путь воздействия: экспериментальный direct-relation selector
(приоритет запроса/отношения) и речевая конструкция IS_A. Все его ответы трассируются.
Это калибровка выбора уже известного одношагового пути, не новый многошаговый
рассуждатель. Core waves, genome, factual default и геометрия не оптимизируются.
