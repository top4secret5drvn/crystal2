# Crystal2

Экспериментальная когнитивная архитектура, Python 3.12+, только стандартная библиотека.
Внешние LLM не используются. `CrystalLattice` хранит граф резонаторов и энергии;
`HDCEncoder` кодирует идентичность и выполняет бинарные операции;
`LanguageMembrane` извлекает лингвистические наблюдения;
`CrystalReason` хранит происхождение; `cognitive_modules` содержит пересмотр
убеждений и поиск кандидатов в правила; `verdict9.py` — отдельный интерпретатор.

## Запуск

Из корня checkout, создайте отдельный каталог данных вне репозитория:

```sh
mkdir -p ../crystal2-data
# Только при первом запуске, не перезаписывая накопленные данные:
cp -n learned_language_rules.json bugfix2.cry bugfix_test.cry ../crystal2-data/
cd ../crystal2-data
PYTHONDONTWRITEBYTECODE=1 python3 ../crystal2/main.py
```

Команды CLI: `ввод <текст>`, `думай 1`, `состояние`, `сохрани <имя>`,
`загрузи <имя>`, `выход`. В scripted stdin обязательно передавайте `выход`:
EOF пока обрабатывается некорректно. `verdict9.py` запускает встроенное демо.
Wikipedia-команда `изучи` требует сети; она не нужна для офлайн-проверок.

Из корня checkout:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
PYTHONDONTWRITEBYTECODE=1 python3 tests/benchmark.py
```

Benchmark выводит JSON. Для исходного baseline выгрузите `engine.py`,
`calibration.py`, `cognitive_modules.py` из commit
`feeac6fcaec7b8ba35b1d4542b16a59375841bab` в отдельный каталог и выполните
`python3 tests/benchmark.py --source /path/to/baseline`.

## Граница знания и гипотез

- Сильное соседство — кандидат, не CAUSE. `causal_hypotheses` отдельно от графа.
- `evaluate_causal_link` принимает идентификатор повторённого вмешательства,
  проверку временного порядка и результат. Это контракт с экспериментатором,
  а не автоматическая проверка достоверности предоставленных данных.
- Структурная абстракция — гипотеза. `evaluate_abstraction` требует независимый
  пример: два различных успеха подтверждают, контрпример отклоняет. Исправленное
  свидетельство с тем же ID позволяет пересмотреть результат. Это начальная
  политика проверки, не статистический критерий научного открытия.
- CLI `подтверди` — явное решение оператора; оно не считается независимым тестом.
- Равносильные противоречия возвращают 0 с причиной `противоречие`; отсутствие
  возвращает None; явное неизвестное — 0 с исходной причиной; ложь — -1.
- Текстовые причинные маркеры сохраняются кандидатами с неизвестным направлением.
  Текст с `не` сохраняется наблюдением без графовых утверждений: область отрицания
  пока не разобрана. Это намеренное ограничение прежнего ошибочного поведения.

## Ограничения и совместимость

SHA-кодирование различает символы, но само по себе не приобретает семантику.
Стемминг эвристический, полноценного разбора русского языка нет. Концепты пока
формируются только из унарных предикатов текущего контекста; бинарные отношения
нельзя безопасно превратить в унарные правила. MDL использует определенный
условный бинарный код, а не универсальную меру понимания. Автоматически добавленные
правила интерпретатора остаются экспериментальными гипотезами и требуют внешней
валидации перед использованием в качестве знаний.

Полные и дельта-снимки расширены JSON-трейлером под CRC; старые bundled `.cry`
загружаются. Старые readers игнорируют трейлер и теряют эпистемические метаданные.
Новый reader восстанавливает причины, контексты, статусы, гипотезы и историю.
Не все transient структуры (очереди маркеров, blackboard, фреймы) сериализуются.
Legacy-файлы не содержат свидетельств: их невозможно восстановить из графа.
Защита от произвольно поврежденного бинарного файла и атомарность загрузки
остаются отдельной задачей; не используйте снимки из недоверенных источников.
