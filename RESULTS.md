# Результаты предыдущей итерации (P0)

## Исходное состояние и воспроизведение

Baseline: feeac6fcaec7b8ba35b1d4542b16a59375841bab. Пять первых
регрессий воспроизведены до изменения P0/HDC: все пять падали.
Отдельно до исправлений воспроизведены: накопление дубликатов концептов,
неучет отрицательных примеров в стоимости MDL, превращение текстового маркера
в CAUSE, отрицание класса вместо отношения, потеря гипотез и удаление неизмененных
ребер в energy-only delta. После изменений 18 тестов проходят.

## Изменения

Корреляции больше не подтверждают причинность; кандидат хранит источник,
уверенность, контекст и свидетельства отдельно от причинного графа.
Автоматическое подтверждение по support/count удалено из всех трех ветвей сна.
Добавлены независимая проверка, отклонение, пересмотр и канонизация пары абстракций.
История убеждений сохраняется; revision engine пересчитывает победителей при
изменении надежности и отзыве источника. Unknown не подавляет известные наблюдения,
контексты изолированы, равный конфликт сохраняется явно.

Bundle использует воспроизводимый, независимый от порядка tie-vector вместо
систематического нуля. Encode/XOR/invert не заменены.
MDL считает стоимость модели и исключений; повторный анализ и вставка правил
не накапливают дубликаты. Неунарные и смешанные контекстные факты исключены.
Отрицание без надежного разбора сохраняется наблюдением, а не ложностью объекта.

Снимки сохраняют эпистемические данные в совместимом JSON-расширении с CRC.
Исправлена потеря ребер в дельте и восстановление следующего ID.
Удалены отслеживаемые pyc; исходные бинарные снимки не изменены.

## Измерения A–D

Seed 1729, 48 обучающих объектов, 20 независимых валидационных и 20 тестовых.
Синтетический настоящий паттерн и ложная корреляция; тестовые target labels
не поступают в поиск правил или предсказатель. Предсказания строятся по antecedents.
Валидация и тест используют разные ID. Объекты не заданы системе заранее.

| Режим | Baseline accuracy / FP | После accuracy / FP |
|---|---|---|
| Без абстракций (всегда отсутствие положительного предсказания) | 0.40 / 0 | 0.40 / 0 |
| Кандидаты без независимой проверки | 0.60 / 8 | 1.00 / 0 |
| С проверкой на независимых примерах | 1.00 / 0 | 1.00 / 0 |

В текущей версии проверенный режим использует lifecycle гипотез CrystalLattice;
для baseline эта политика реализована в harness, поскольку такого API раньше не было.
Это не apples-to-apples сравнение всего механизма сна: benchmark проверяет перенос
извлеченных унарных закономерностей, а не способность топологической сингамии
самостоятельно выбирать предикаты. Независимая проверка уже устраняла ложную
корреляцию в baseline; дополнительный выигрыш нового MDL здесь равен нулю после
валидации. MDL отсекает ее раньше. Усложнение не объявляется улучшением само по себе.

B: восстановление подавленного убеждения после снижения надежности — false → true.
C: необоснованный CAUSE из корреляции — true → false; явно заданная причинность
сохранена. Это не автоматическое распознавание причин в природе.

В JSON сохранены длительность и peak traced Python memory всего опыта и каждого
режима. Это одиночные измерения, не статистика быстродействия; память не равна RSS.
Повторный запуск воспроизводит качественные результаты, время и память колеблются.

## Оставшиеся проблемы и следующие гипотезы

- Scope отрицаний и направление русских причинных конструкций требуют отдельного
  корпуса с gold-разметкой. Сейчас система воздерживается, а не угадывает.
- Формирование концептов перебирает комбинации экспоненциально; большой словарь
  не измерен. Политика допуска экспериментальных правил в интерпретатор пока
  не обеспечивает сквозную изоляцию гипотез от всех путей вывода.
- Подтвержденная вручную абстракция может влиять на распространение энергии;
  нужна проверка полезности именно topology-based механизма на нескольких seed.
- История lattice сохранена и доступен отзыв источника; полная синхронизация
  bitwise TruthValue с эпистемическими статусами при всех путях вывода не доказана.
- Операции причинного подтверждения доверяют внешнему экспериментатору; нельзя
  принимать переданные флаги за собственное установление причинности.
- Снимки не являются полным checkpoint всех runtime-структур; загрузка поврежденных
  данных пока не транзакционная. Нужны fuzzing и версионированная миграция формата.
- Следующий исследовательский опыт: class-balanced наборы с неполными и шумными
  наблюдениями, несколькими seed и фиксированным бюджетом правил; сравнить текущий
  MDL с проверкой на независимых примерах без изменения остальных механизмов.
